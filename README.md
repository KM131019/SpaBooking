# Đề tài: TỰ ĐỘNG HÓA KIỂM THỬ WEBSITE ĐẶT LỊCH SPA SỬ DỤNG SELENIUM VỚI AI HỖ TRỢ THIẾT KẾ TEST CASE

## Mô tả
Xây dựng hệ thống kiểm thử tự động cho website đặt lịch spa bằng Selenium WebDriver. AI được sử dụng để hỗ trợ thiết kế và sinh các test case kiểm thử.

## Công nghệ sử dụng
- Selenium WebDriver
- JMeter
- OWASP ZAP
- Allure Report

## Các chức năng kiểm thử
- Đăng ký
- Đăng nhập
- Quên mật khẩu
- Đổi mật khẩu
- Đặt lịch dịch vụ
